# Globe boundary data

`countryBorders.json` contains simplified, locally bundled country/coastline outlines derived from Natural Earth 1:110m, `ne_110m_admin_0_countries.geojson` (177 country features). Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/ . Source: https://github.com/nvkelso/natural-earth-vector/tree/master/geojson . Coordinates are rounded to two decimal places and simplified for a decorative, offline login animation; do not use for legal, navigational or authoritative political boundaries.
