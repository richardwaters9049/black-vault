# Desktop packaging artwork

`icon-master.png` is the retained source artwork for packaged application icons. Generated platform resources live in `../src-tauri/icons/` and are referenced by the Tauri configuration. Keep the source so future icon regeneration is reproducible.

From `desktop/`, regenerate when changing the artwork:

```bash
npm run tauri -- icon assets/icon-master.png --output src-tauri/icons
```

Review generated resources before committing. The animated in-app brand mark is a separate SVG component, `src/components/VaultMark.tsx`. Archived release packages are not regenerated by this command.
